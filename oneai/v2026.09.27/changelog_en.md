# OneAI v2026.09.27 — More connected company data, a more reliable Chat

**Release Date:** 2026-09-27

## Highlights

- **Four new ways to connect key business data:** GitLab projects, NinjaOne, Microsoft Dynamics 365 Business Central, and Dynamics 365 Sales are now available as connectors. Teams can use code, sales information, and device, alert, and patch data directly in AI Chat.
- **An assistant that remembers preferences:** Personal preferences can now be retained over time, helping AI Chat apply recurring ways of working and requirements more consistently.
- **More reliable long conversations:** Long chats are now summarized automatically and reliably. Important context is retained while conversations can continue smoothly.

## Improvements

- **Expanded GitHub workflows in Chat:** GitHub users can merge pull requests, search code, and edit files directly from AI Chat.
- **Agents with clearer controls:** The agent builder now includes an approval queue and team approvals. Defined action budgets are enforced so agents operate within clear boundaries.
- **A more responsive Chat experience:** After confirming an action, responses now appear live in Chat again—without requiring a page refresh.

## Under the Hood

We further improved the reliability of connectors, document and context processing, and other core Chat workflows.

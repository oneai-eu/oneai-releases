# OneAI v2026.09.27 — Des données d’entreprise mieux connectées, un Chat plus fiable

**Release Date:** 2026-09-27

## Points forts

- **Quatre nouvelles façons de connecter des données métier clés :** les projets GitLab, NinjaOne, Microsoft Dynamics 365 Business Central et Dynamics 365 Sales sont désormais disponibles comme Connectors. Les équipes peuvent utiliser directement dans AI Chat du code, des informations commerciales ainsi que des données sur les appareils, les alertes et les correctifs.
- **Un assistant qui mémorise les préférences :** les préférences personnelles peuvent désormais être conservées dans le temps, ce qui aide AI Chat à appliquer plus systématiquement les méthodes de travail et exigences récurrentes.
- **Des conversations longues plus fiables :** les longs chats sont désormais résumés automatiquement et de manière fiable. Le contexte important est préservé, tandis que les conversations peuvent se poursuivre fluidement.

## Améliorations

- **Des workflows GitHub étendus dans Chat :** les utilisateurs de GitHub peuvent fusionner des pull requests, rechercher du code et modifier des fichiers directement depuis AI Chat.
- **Des agents aux contrôles plus clairs :** le générateur d’agents inclut désormais une file d’attente d’approbation et des validations d’équipe. Les budgets d’action définis sont appliqués afin que les agents opèrent dans des limites claires.
- **Une expérience Chat plus réactive :** après la confirmation d’une action, les réponses s’affichent à nouveau en direct dans Chat, sans nécessiter de rechargement de la page.

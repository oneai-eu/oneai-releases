OneGlue v0.256.0 tunes background synchronization and internal database queries for lower load (permission-revocation hints to connected oneAI workspaces now arrive within about a minute instead of about ten seconds, with enforcement on OneGlue's own side unaffected), and makes the audit log cleaner and more trustworthy -- repeated automated activity is now aggregated into periodic summary entries instead of flooding the log, automated background actions are attributed to the system rather than a person, a false-alarm class in token-cleanup reporting is fixed, and successful automated actions now record network origin details like failed attempts always did.

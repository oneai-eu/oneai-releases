OneGlue v0.267.0 adds a "Duplicate" button to configurations, networks, contacts, locations, domains, and flexible assets, pre-filling a new item from an existing one while keeping unique identifiers (serial numbers, MAC addresses, domain names) empty and highlighting the fields you should double-check; domains with a linked registrar credential are now kept up to date automatically via a nightly sync plus an on-demand "Sync from registrar now" button; and creating a flexible asset now opens its detail page directly.

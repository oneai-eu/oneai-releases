OneGlue v0.276.0 adds an in-app support and feature-request form (profile menu → Support & feature request) with a mandatory choice between support case and feature request that decides routing and urgency, the technical context of the current page attached automatically, its own case number, an e-mail confirmation and a "My requests" list showing delivery state — plus a "Report this problem" button that appears in place when the application hits an error, with the error context pre-filled; attachments can finally be deleted (the attempt previously failed) and deleted files go to a trash showing when they were removed and how long they stay restorable, across attachments on documents, passwords, certificates and contacts.

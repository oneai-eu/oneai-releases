# OneGlue v0.282.0 — What's New

**Released:** 2026-10-15

**OneGlue is ready for the new oneAI integration: a personal oneAI key, 44 tools and device analyses from the chat.**

## Your personal oneAI key

- **Store your own oneAI key under "Personal integrations".** OneGlue agents then work with your own access. The key is checked when you save it, stored encrypted and never shown again.
- **Administrators decide which oneAI instance OneGlue talks to.** Only official oneAI addresses are allowed.

## More OneGlue in oneAI — once the new integration is rolled out

- **44 tools for your oneAI chat:** devices, networks, locations, domains, certificates, contacts, virtual machines, documents and links. They become available as soon as the new oneAI integration is rolled out for your organization.
- **Device analysis from the chat:** ask a OneGlue agent to analyse a device. The report appears in the chat and is saved as a document on the device. The agent only proposes changes — you approve them in OneGlue.
- **Reading works right away; you confirm every change in oneAI.**

## Security

- **Passwords and secrets never leave OneGlue.** The tools return metadata at most, and credentials are stripped from addresses.
- **Every access through oneAI is logged.**

## Small improvements

- Devices with a GlueAgent no longer count as "changed" every time the agent checks in — only when something actually changed.
- Documents can be deleted permanently again without an error.
- Custom fields on contacts, locations and networks are saved correctly again when you edit them.

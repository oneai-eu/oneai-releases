OneGlue v0.282.0 gets OneGlue ready for the new oneAI integration. Users can store their own oneAI key under "Personal integrations"; OneGlue agents then work with their own access, the key is checked on save, stored encrypted and never shown again, and administrators choose which official oneAI instance OneGlue talks to. Once the new oneAI integration is rolled out for an organization, its oneAI chat gets 44 OneGlue tools for devices, networks, locations, domains, certificates, contacts, virtual machines, documents and links, plus device analyses by a OneGlue agent whose report appears in the chat and is saved on the device; reading works right away, every change is confirmed in oneAI, and the agent only proposes changes for approval in OneGlue. Passwords and secrets never leave OneGlue, and every access through oneAI is logged. Smaller fixes: devices with a GlueAgent no longer count as changed on every check-in, permanent document deletion works again, and custom fields on contacts, locations and networks save correctly again.

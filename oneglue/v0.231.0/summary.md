OneGlue v0.231.0 is a security-hardening release for the browser-connect step of Passkey-Safe. The confirmation code used to connect a browser is now protected against repeated wrong-code attempts, unfinished connection requests expire automatically instead of lingering, and an edge rate-limit blunts automated abuse before it reaches the app. Your stored passkeys, permissions, sharing, and audit trail are untouched — this release only strengthens the browser-connect flow introduced in the previous version.

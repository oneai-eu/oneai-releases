OneGlue v0.233.0 adds recovery codes as a managed MFA method: store the one-time recovery / backup codes a service hands you right next to that service's password and authenticator. Generate a set (shown once, with copy + PDF), keep it encrypted at rest, reveal it under the secret's own permissions and approvals (every reveal audit-logged), mark codes used to track what's left, and regenerate a fresh set when they run low. This release also brings the worker status back onto the configuration page for GlueAgent-managed hosts — a read-only overview of the host's worker / `.glue` state, facts, and most recent automation runs, right where you'd expect it.

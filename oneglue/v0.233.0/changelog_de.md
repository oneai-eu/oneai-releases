# OneGlue v0.233.0 — Neuigkeiten

**Veröffentlicht am:** 2026-07-29

**Ein Zuhause für Ihre Wiederherstellungscodes.** OneGlue kann jetzt die Einmal-Wiederherstellungs- bzw. Backup-Codes speichern und verwalten, die Ihnen ein Dienst ausgibt — direkt neben dem Passwort und dem Authenticator dieses Dienstes, als verwaltete Methode am Secret.

## Wiederherstellungscodes als verwaltete MFA-Methode

- **Erzeugen und speichern Sie ein Set Einmal-Codes** für einen Login — einmalig bei der Erstellung angezeigt, mit Kopieren + PDF-Download, danach im Ruhezustand verschlüsselt wie jedes andere Secret.
- **Zeigen Sie sie an, wenn Sie einen brauchen** — unter denselben Berechtigungen und Freigaben, die das Secret selbst schützen, jede Anzeige im Audit-Log.
- **Markieren Sie einen Code als benutzt**, behalten Sie den Überblick, sehen Sie „verbleibend von gesamt" auf einen Blick und erzeugen Sie ein frisches Set, wenn es knapp wird (das alte Set wird ungültig, mit klarem Hinweis).

## Agent-verwaltete Hosts: Worker-Status zurück auf der Seite

- Für einen per GlueAgent verwalteten Host zeigt die Konfigurationsseite wieder eine schreibgeschützte Übersicht über den Worker-/`.glue`-Status, Host-Fakten und die letzten Automatisierungsläufe — genau dort, wo man sie erwartet, ohne Suchen.

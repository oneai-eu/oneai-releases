# OneGlue v0.221.0 — What's New

**Release Date:** 2026-07-25

**A cleaner, clearer workspace.** This release is a set of usability improvements: device detail pages now follow a consistent layout, shared-credential labels read the same everywhere, and your favorites rise to the top of more lists. Nothing about who can see or do what changes — these are presentation improvements only.

## Consistent device detail pages

- **Device (configuration) detail pages now follow a fixed layout.** What the device is and how to reach it (its identity, connection actions, and credentials) always comes first; documentation and related items come next; automation and advanced tools always come last. As we add new capabilities, sections no longer shuffle around — the page stays where you expect it.
- Sections that don't apply to a device simply don't appear, so the page stays focused.

## Clearer credential labels

- **"Shared credentials" now reads consistently across the app.** A label that previously differed from screen to screen has been unified, so the same concept always has the same name.
- **Each credential section on a device now has a one-line explanation** — so it's immediately clear whether you're looking at passwords stored on the device, shared credentials that apply to it, or the agent's bootstrap access.

## Favorites rise to the top

- **On contacts, locations, and flexible assets, your starred favorites now sort to the top of the list** — the same behavior you already have on configurations, passwords, and networks. Lists that are ordered by something meaningful (such as documents by last edited, or domains and certificates by expiry) keep their order and simply show the star.

# OneGlue v0.291.1 — What's new

**Released:** 2026-10-25

**OneGlue now tells you on its own when an agent goes down.**

- **Agents that go down are noticed right away.** If an agent has not checked in for an hour, the administrators of your tenant receive an email – and a second one as soon as it is reachable again. Devices that have already been offline for a while do not trigger a message when this is introduced. You can turn the messages off in the tenant settings under "Agent offline alerts".
- **Virtual machines for your whole team.** Anyone with access to an organization now also sees its virtual machines with all details, including in the AI assistant. The same groups and permissions apply as for every other entry.
- **AI assistant for your customers – only if you want it.** You can allow individual customer organizations to use the AI assistant with their own oneAI account. There is one switch for your tenant and one per organization; both start switched off. Your customers only see their own organization, and their usage never runs through your oneAI account. The settings always show how many customer users are using the assistant.
- **Straight to the right place after signing in.** After every sign-in – including with a recovery code – you and your customers land directly in your own organization.
- **No more error pages for your customers** when a feature is not enabled for their account.
- **New agent.** Agents on Linux update automatically. On Windows the agent is now better protected against tampering, runs more quietly and shows its publisher and version in Windows; existing Windows installations get this with a reinstall.
- **Security and operations:** security updates for all components we use and stricter protection of the servers that remote access runs through. We now also back up your data to a new external location in the EU, and every backup is monitored.

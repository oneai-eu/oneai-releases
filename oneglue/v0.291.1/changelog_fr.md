# OneGlue v0.291.1 — Nouveautés

**Publié le :** 2026-10-25

**OneGlue vous prévient désormais de lui-même lorsqu'un agent tombe en panne.**

- **Les agents en panne sont repérés immédiatement.** Si un agent ne se manifeste pas pendant une heure, les administrateurs de votre tenant reçoivent un e-mail, puis un second dès qu'il est de nouveau joignable. Les appareils déjà hors ligne depuis un moment ne déclenchent aucun message lors de la mise en place. Vous pouvez désactiver ces messages dans les paramètres du tenant, sous « Alertes Agent hors ligne ».
- **Les machines virtuelles pour toute votre équipe.** Toute personne ayant accès à une organisation voit désormais aussi ses machines virtuelles avec tous les détails, y compris dans l'assistant IA. Les mêmes groupes et autorisations s'appliquent que pour toutes les autres entrées.
- **Un assistant IA pour vos clients, seulement si vous le souhaitez.** Vous pouvez autoriser certaines organisations clientes à utiliser l'assistant IA avec leur propre compte oneAI. Il existe un interrupteur pour votre tenant et un par organisation ; les deux sont d'abord désactivés. Vos clients ne voient que leur propre organisation, et leur utilisation ne passe jamais par votre compte oneAI. Les paramètres indiquent à tout moment combien d'utilisateurs clients se servent de l'assistant.
- **Directement au bon endroit après la connexion.** Après chaque connexion, y compris avec un code de récupération, vous et vos clients arrivez directement dans votre propre organisation.
- **Plus de pages d'erreur pour vos clients** lorsqu'une fonction n'est pas activée pour leur compte.
- **Nouvel agent.** Les agents sous Linux se mettent à jour automatiquement. Sous Windows, l'agent est désormais mieux protégé contre les manipulations, fonctionne plus discrètement et affiche son éditeur et sa version dans Windows ; les installations Windows existantes en bénéficient lors d'une réinstallation.
- **Sécurité et exploitation :** mises à jour de sécurité pour tous les composants que nous utilisons et protection renforcée des serveurs par lesquels passent les accès à distance. Nous sauvegardons en outre vos données sur un nouveau site externe dans l'UE, et chaque sauvegarde est surveillée.

# OneGlue v0.308.0 — Neuigkeiten

**Veröffentlicht am:** 2026-11-15

**oneAI-Einstellungen an einem Ort**

- Unter „Integrationen → oneAI“ findest du jetzt alle Einstellungen zur oneAI-Anbindung: den neuen Schalter „oneAI-Integration erlauben“, den Assistenten für Kunden und den oneAI-Server. Einzelne Organisationen können einen eigenen oneAI-Server bekommen; ein oneAI-Schlüssel wird dabei nur an seinen eigenen Server geschickt. Die alte Kopplung über das Tenant-Pairing gibt es nicht mehr. oneAI verbindest du mit deinem persönlichen API-Schlüssel.
- *Hinweis für Admins:* Ist der Schalter aus, zeigt oneAI bis zum nächsten Update einen irreführenden Hinweis „neuen Schlüssel erstellen“. Wieder einschalten genügt, ein neuer Schlüssel ist nicht nötig.

# OneGlue v0.308.0 — Nouveautés

**Publié le :** 2026-11-15

**Tous les réglages oneAI au même endroit**

- Sous « Intégrations → oneAI », tu trouves désormais tous les réglages de la connexion oneAI : le nouvel interrupteur « Autoriser l'intégration oneAI », les agents clients et le serveur oneAI. Chaque organisation peut recevoir son propre serveur oneAI ; une clé oneAI n'est envoyée qu'à son propre serveur. L'ancienne connexion via l'appairage du locataire n'existe plus. Tu connectes oneAI avec ta clé API personnelle.
- *Note pour les administrateurs :* Tant que l'interrupteur est désactivé, oneAI affiche jusqu'à sa prochaine mise à jour une indication trompeuse « créer une nouvelle clé ». Il suffit de le réactiver ; une nouvelle clé n'est pas nécessaire.

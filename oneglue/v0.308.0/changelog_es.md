# OneGlue v0.308.0 — Novedades

**Publicado el:** 2026-11-15

**Todos los ajustes de oneAI en un solo lugar**

- En «Integraciones → oneAI» encontrarás ahora todos los ajustes de la conexión con oneAI: el nuevo interruptor «Permitir la integración de oneAI», los agentes de clientes y el servidor de oneAI. Cada organización puede tener su propio servidor de oneAI; una clave de oneAI solo se envía a su propio servidor. La antigua conexión mediante el emparejamiento del tenant ya no existe. Conectas oneAI con tu clave API personal.
- *Nota para administradores:* Mientras el interruptor esté desactivado, oneAI muestra hasta su próxima actualización un aviso engañoso «crear una clave nueva». Basta con volver a activarlo; no hace falta una clave nueva.

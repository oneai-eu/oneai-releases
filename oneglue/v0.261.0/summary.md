OneGlue v0.261.0 is a targeted reliability release: adding a passkey from Profile → Security now works reliably every time (fixing an occasional "No tenant matches" error), network addresses with extra bits set beyond their prefix now show a clear inline error with a suggested correction instead of a generic server error (covering both Networks and the SSH connection allowlist), and behind-the-scenes diagnostics for SCVMM inventory synchronization and internal build-failure tracking were improved.

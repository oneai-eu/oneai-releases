OneGlue v0.222.0 lets a password carry multiple two-factor (TOTP) methods instead of just one — for example a Primary and a Backup — each generating its own current code on demand. Passwords that already had a two-factor code keep working automatically as the first "Primary" method. You can import several accounts at once by scanning a Google Authenticator "export/transfer accounts" QR, and the QR scanner no longer silently ignores a code it can't read. MFA methods are protected exactly like the password itself — the same permission and the same approval (multi-person quorum where configured) are required to reveal a code — and MFA seeds never appear in logs, exports, or integrations.

# OneGlue v0.307.1 — Nouveautés

**Publié le :** 2026-11-14

**Connecter oneAI avec une clé personnelle**

- Tu connectes désormais oneAI avec ta propre clé API au lieu de passer par l'appairage du Tenant. Sous « Intégrations personnelles → Clés API personnelles », tu crées une clé (valable 90 jours par défaut) et tu la saisis dans oneAI. oneAI voit exactement ce que tu as le droit de voir dans OneGlue. Les modifications des documents arrivent dans oneAI par push en moins d'une minute, et oneAI effectue en plus un rapprochement toutes les 6 heures.
- Pour l'assistant IA de OneGlue, tu peux désormais enregistrer ta clé API oneAI avec le serveur oneAI correspondant.

# OneGlue v0.307.1 — Novedades

**Publicado el:** 2026-11-14

**Conecta oneAI con una clave personal**

- Ahora conectas oneAI con tu propia clave API en lugar de usar el emparejamiento del Tenant. En «Integraciones personales → Claves API personales» creas una clave (válida por defecto durante 90 días) y la introduces en oneAI. oneAI ve exactamente lo que tú puedes ver en OneGlue. Los cambios en los documentos llegan a oneAI mediante push en el plazo de un minuto, y además oneAI sincroniza cada 6 horas.
- Para el asistente de IA de OneGlue, ahora puedes guardar tu clave API de oneAI junto con el servidor de oneAI correspondiente.

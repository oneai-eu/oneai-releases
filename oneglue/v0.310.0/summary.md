OneGlue v0.310.0: The AI assistant now uses a model that is enabled in your oneAI organization when you don't pick one; if you pick a model that is not enabled, the message lists the available ones. Large lists and documents reach the assistant in shortened form, and errors explain what happened. On Linux devices the GlueAgent sets up the assistant's access with a restricted account, automatically from agent version 0.5.32; assistant diagnostics run through the connected GlueAgent. Network cards no longer reported by an agent are removed, and tenant admins can revoke personal API keys.
